# plowheroes.github.io

This repository only redirects https://plowheroes.github.io (and any page under it) to the live Plow Heroes site at **https://www.plowheroes.com**.

- The real site's code is in [plowheroes/Plow-Heroes](https://github.com/plowheroes/Plow-Heroes) and is hosted on Cloudflare.
- `index.html` and `404.html` are identical: they send visitors to the same path on www.plowheroes.com.
- Nothing here needs updating when the site changes.

The previous contents of this repository (an older copy of the site) were deleted on 2026-11-12; a backup bundle is kept in the Plow-Heroes project folder at `archive/plowheroes.github.io-backup-2026-11-12.bundle` (local only).
